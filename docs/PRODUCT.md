# Why CutBundle?

The focus is the finished export pack, not a single cutout: gather six photos, group them by product, apply consistent background and margins, inspect the result, and export twelve correctly sized images in one archive.

This is a deliberately small local alternative. Paid editors already support batch work, alignment, margins, and SKU/file naming. Those are not novel inventions claimed by this project. The tradeoff here is an offline, account-free Korean-first workflow with predictable exports and limited editing scope.

## Demand hypotheses, not market proof

- Photoroom's official help page, [Export limit](https://help.photoroom.com/en/articles/15284788-export-limit), updated July 16, 2026, describes monthly export accounting. This suggests predictable local exports may matter to some users; it does not prove they would adopt this app.
- Existing open-source projects such as [DeleteBackground](https://github.com/TermiSenpai/DeleteBackground) already offer folder processing, plain backgrounds, preview, and cancel controls. A useful contribution needs to complete a seller's grouping/output workflow rather than just rename a remover GUI.
- Developer/community complaints about quotas, repetitive formatting, and batch handling are qualitative prompts for investigation, not representative market research.

The name 컷묶음 / CutBundle is a working project name. An exact-name web search did not find an identical photo app; that is not trademark clearance.
